# What's new

Short notes for Jordan: what to look for after each install. Newest first.

## Not installed yet

- Turning a mod on or off updates every row's notes at once: no leftover "(off)" until the next redraw.
- Libraries say "Required for 3 mods" (red when the library itself is off).
- "Needs: X": X is green when it's on, red when it's off, on every row (also for mods that are off).
- Turned-on-since-launch titles stay bright gold; turned-off ones are a dimmer, dusky gold.
- Profile bar:
  - "Unsaved •" (coral) with Save / Save as new / Discard right beside it; New / Duplicate / Rename / Delete on the right.
  - New, Duplicate, Save as new and Rename open a name box with Save / Cancel / Clear; copies are offered as "Name (1)".
  - Empty or taken names show a warning and can't be saved.
  - Leaving a profile with unsaved changes keeps them with it: "Name *" in the list, and they come back when you return.
  - The list shows each profile's mod count and save date; clicking the picker again closes it.
- Right-click menus are our own now: a dot marks the current choice (e.g. the mod's category).

## Installed 2026-10-11

- Thumbnail in the info panel stays small (the game's 500x380 minimum size was overriding ours).
- Profile bar: plain name with "Unsaved •" beside it; buttons on the right.
- Leaving the Modding page from Load Order reopens it on the main list.

# For your review

Choices I made on my own; say if any should change.

- **New** makes a blank profile (only Spire Mod Manager on), since Duplicate now copies the current one.
- **Clicking away from the profile name box cancels** (nothing is created or renamed without Save or Enter). Tags, alias and notes still save when you click away, so typed text is never lost.
- **"Unsaved •" is coral**, different from the gold names and the red warnings.
- **Old "Name (edited 14:19)" profiles** from the previous build are ordinary profiles now; delete any you don't want.
- **Profile list details**: "5 mods · Oct 11" counts mods that are on (not counting this one) and shows when it was last saved; profiles from before this build show no date until saved once.
